# NILEX Authentication API collection

Import `NILEX-Authentication.postman_collection.json` into Postman and run the requests in collection order while the application is available at `http://localhost:8080`.

The collection generates a unique test email at runtime. Access and refresh tokens are held only in Postman runtime collection variables. The checked-in file contains no real credentials, secrets, or tokens.

Interactive OpenAPI documentation is available at `http://localhost:8080/swagger-ui.html`, with the raw specification at `http://localhost:8080/v3/api-docs`.
